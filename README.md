# TaskMaster - Агрессивно Красивый Задачник

Современное веб-приложение для управления важными событиями с агрессивно красивым дизайном и полной кастомизацией.

## Особенности

- 🎨 **Агрессивно красивый дизайн** - смелые цвета, градиенты, анимации и эффекты
- ⚙️ **Полная кастомизация** - настройте цвета, иконки, типы событий под свои нужды
- 📅 **Управление событиями** - создавайте, редактируйте и отслеживайте важные события
- 💾 **Локальное хранение** - все данные сохраняются в вашем браузере
- 📱 **Адаптивный дизайн** - работает идеально на всех устройствах
- 🔒 **Приватность** - никаких серверов, никакого сбора данных

## Технологии

- HTML5
- CSS3 (с современными возможностями: переменные, гриды, флексбоксы)
- JavaScript (ES6+)
- Particles.js для фона
- LocalStorage для хранения данных

## Как использовать

1. Откройте `index.html` в любом современном браузере
2. Используйте форму для создания новых событий
3. Настройте цвет, иконку и тип события
4. Просматривайте свои события в разделе "Ваши важные события"
5. Фильтруйте события по типу
6. Редактируйте или удаляйте события по необходимости

## Настройка и кастомизация

### Изменение цветовой схемы
Основные цвета определены в `styles.css`:
- Основной акцент: `#ff6b6b` (коралловый)
- Вторичный акцент: `#4ecdc4` (бирюзовый)

Для изменения цветовой схемы отредактируйте значения в градиентах и цветах throughout the stylesheet.

### Добавление новых типов событий
Отредактируйте `<select id="event-type">` в `index.html` и добавьте соответствующие стили в `styles.css`.

### Добавление новых иконок
Отредактируйте секцию `.icon-picker` в `index.html`, добавив новые кнопки с желаемыми эмодзи.

## Агрессивно красивые элементы дизайна

- **Градиентный фон** с плавными переходами
- **Анимированный логотип** с эффектом свечения
- **Плавающие карточки событий** в геросекции
- **Гlassmorphism эффекты** через backdrop-filter
- **Плавные анимации** при ховере и клике
- **Динамические частицы** в фоне через Particles.js
- **Смешанные режимы наложения** и градиентный текст
- **Тени и свечения** для глубины и объема

## Поддержка браузеров

TaskMaster работает во всех современных браузерах:
- Chrome 64+
- Firefox 60+
- Safari 12+
- Edge 79+

Для оптимальной работы рекомендуется использовать последние версии браузеров.
