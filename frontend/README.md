# TaskMaster Fantasy Frontend

Это фронтенд-часть приложения TaskMaster Fantasy - продуктивного приложения в стиле тёмного фэнтези.

## Особенности

- 🌑 Тёмная фэнтези тема с готическими элементами
- ⚡ Современный React 18 с TypeScript
- 💾 Управление состоянием с Zustand
- 🛡️ Аутентификация с JWT токенами
- 📱 Адаптивный дизайн для всех устройств
- ✨ Плавные анимации и микровзаимодействия
- 🔐 Безопасное хранение токенов в localStorage
- 🌍 Поддержка международной локализации (русский язык)

## Технологический стек

- **React 18** - библиотека для построения пользовательских интерфейсов
- **TypeScript** - строгая типизация для надежного кода
- **Zustand** - легковесное управление состоянием
- **React Router DOM 6** - навигация и маршрутизация
- **Axios** - HTTP клиент для работы с API
- **Date-fns** - работа с датами и временем
- **React Toastify** - уведомления

## Структура проекта

```
src/
├── components/         # Переиспользуемые компоненты (модальные окна, кнопки и т.д.)
├── contexts/           # React контексты (если понадобятся)
├── hooks/              # Кастомные хуки
├── pages/              # Страницы приложения
├── services/           # Сервисы для работы с API
├── store/              # Zustand хранилища
├── styles/             # Глобальные стили и переменные
├── utils/              # Вспомогательные функции и константы
├── App.tsx             # Корневой компонент
└── index.tsx           # Точка входа
```

## Установка и запуск

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите в режиме разработки:
   ```bash
   npm start
   ```
   Приложение будет доступно по адресу http://localhost:3000

3. Соберите produkcion версию:
   ```bash
   npm run build
   ```
   Сборка будет размещена в папке `build/`

## Переменные окружения

Создайте файл `.env` в корне frontend папки с následujющими переменными:

```
REACT_APP_API_URL=https://your-backend-url.com
```

## Доступность
